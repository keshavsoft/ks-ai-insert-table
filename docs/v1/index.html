📖 Overview

ks-ai-insert-table is a specialized developer utility that automatically scaffolds new table routers and inserts registration hooks into the central routes.js file.

It maps endpoint schemas, copies boilerplate router logic, and safely updates target route files without code duplication.

The project is part of the KeshavSoft API Generation Suite, helping developer CLIs and VS Code integrations generate clean routes efficiently.

✨ Features

✅ Automatic table router scaffolding
✅ Central routes.js import injections
✅ router.use() configuration hooks
✅ Safe duplicate prevention (Idempotent updates)
✅ Precheck validation using ks-ai-insert-table-check
✅ Supports multiple schema mappings
